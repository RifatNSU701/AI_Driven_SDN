# AI-Powered SDN Threat Protection System

**Author:** Rifat Khan

## Overview
An end-to-end closed-loop Software-Defined Networking (SDN) security prototype combining OpenFlow 1.3 telemetry, machine-learning anomaly detection, and automated Open vSwitch policy enforcement.

## Architecture
- **Data Plane:** Mininet & Open vSwitch (OpenFlow 1.3)
- **Control Plane:** Ryu SDN Controller (scripts/sdn_controller.py)
- **Detection & Enforcement:** Python ML Engine, FastAPI Server, and Streamlit Monitoring Dashboard
